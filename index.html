📄 البرومبت الكامل

انسخ النص بالكامل والصقه مباشرة في Intigravity.

🧱 Stack المطلوب

  • Flutter (Clean Architecture + MVVM)
  • Supabase: Auth (Phone OTP + Email)
  • PostgreSQL Database
  • Storage (Images)
  • Realtime (Chat)
  • Google AdMob
  • In-App Paid Promotion System

🔐 Supabase Configuration (IMPORTANT)

استخدم متغيرات بيئة فقط، بدون مفاتيح صريحة داخل الكود:

await Supabase.initialize(
  url: const String.fromEnvironment('SUPABASE_URL'),
  anonKey: const String.fromEnvironment('SUPABASE_ANON_KEY'),
);

❌ لا تضع المفاتيح مباشرة في الكود

✅ اعتمد على .env أو --dart-define

👤 Authentication

  • Phone Number + OTP
  • Email & Password
  • Google Sign-in (اختياري)

Roles:

🗂️ Database Schema (Supabase)

users

id (uuid), name, phone, role, rating, created_at

categories

id, name, icon

listings

id, title, description, price, category_id, user_id, city, is_promoted, promoted_until, views, created_at

promotions

id, listing_id, type, start_date, end_date, price

chats

id, listing_id, buyer_id, seller_id

messages

id, chat_id, sender_id, message, created_at

🛡️ Security (RLS Required)

  • المستخدم يرى كل الإعلانات
  • لا يعدل أو يحذف إلا إعلاناته
  • الشات خاص بالأطراف فقط
  • Admin فقط يراجع ويحذف
auth.uid() = user_id
